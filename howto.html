별담 사용 방법

입구 정하기부터 파일 옮기기까지 · 2026년 10월 기준

한눈에 보기: ① 그림 속 한 곳을 누르고 ② 5×5 점을 5개 이상 이어 패턴을 그리면 비밀방이 열려요. 방 안에서 폴더를 만들고, 사진·동영상·파일을 복사 또는 이동으로 가져오면 폰 안에만 암호화되어 보관돼요.

  1. 처음 입구 정하기
  2. 비밀방 들어가기
  3. 폴더 만들기
  4. 사진·동영상 가져오기
  5. 모든 파일 가져오기
  6. 복사와 이동 고르기
  7. 사진·동영상 보기
  8. 파일 옮기기
  9. 폰으로 복원·삭제
  10. 비밀방 추가하기
  11. 패턴·작업 비밀번호 바꾸기
  12. 자동 잠금
  13. 일상방 채워 두기

1처음 입구 정하기

  1. 처음 실행하면 안내 3장이 나와요. 마지막에 비밀방 등록을 누르세요.
  2. 방 이름을 정하고 입구 설정을 눌러요.
  3. 그림 속 하늘색 원 15곳 중 한 곳을 누르세요. 창문, 문, 가로등, 별, 달이 있어요. 고른 곳은 금색으로 바뀌어요.
  4. 아래 5×5 점을 5개 이상 이어서 패턴을 그려요.
  5. 같은 위치를 누르고 같은 패턴을 한 번 더 그리면 등록 끝이에요.
  6. 마지막으로 복원·삭제 때 쓰는 작업 비밀번호(8자 이상)를 두 번 입력해요.

💡 잘못 골랐다면 아래 다시 입력하기를 누르면 처음부터 정할 수 있어요. 위치와 패턴은 잊으면 복구할 수 없으니 꼭 기억해 두세요.

2비밀방 들어가기

  1. 잠금 화면(밤마을 그림)에서 등록한 그림 위치를 먼저 누르세요. 누르면 살짝 빛나요.
  2. 바로 아래 점에 패턴을 그리면 비밀방이 열려요.

💡 잠금 화면에는 입구 위치가 표시되지 않아요. 그림을 누르지 않고 패턴만 그리면 “틀렸습니다”가 나와요.

3폴더 만들기

  1. 비밀방 첫 화면에서 ＋ 새 폴더를 눌러요.
  2. 이름을 적고 저장하면 폴더 카드가 생겨요.
  3. 폴더 안에서 이름 변경도 할 수 있어요.

💡 화면 위쪽에 지금 쓰는 용량이 보여요 (무료는 1GB까지).

4사진·동영상 가져오기

  1. 폴더 안에서 + 파일 추가 → 사진 · 동영상을 눌러요.
  2. 사진만 보기 / 동영상만 보기 / 사진 + 동영상 중에서 골라요.
  3. 갤러리가 열리면 가져올 사진·영상을 여러 개 탭하고 완료를 눌러요.

5모든 파일 가져오기 (문서 등)

  1. + 파일 추가 → 모든 파일을 눌러요.
  2. 처음 한 번만 파일이 있는 폴더를 골라 허용해요. 다음부터는 바로 목록이 열려요.
  3. 별담 안 목록에서 파일을 탭하면 ✓ 선택, 다시 탭하면 해제돼요. 폴더를 오가며 여러 곳의 파일을 함께 고를 수 있어요.
  4. 위쪽 확인 (N)을 눌러요.

💡 Android 정책상 ‘Download’ 폴더 자체는 고를 수 없어요. 그 안의 파일은 기본 파일 화면에서 길게 눌러 여러 개 고르세요.

6복사와 이동 고르기

  1. 고른 뒤 “복사할까요, 이동할까요?” 창이 나와요.
  2. 복사: 갤러리 원본은 그대로 두고 비밀방에 한 벌 더 보관해요.
  3. 이동: 암호화 저장과 내용 비교가 끝나면 Android 승인 창이 떠요. 허용을 누르면 갤러리 원본이 휴지통 없이 지워져요.

💡 클라우드 백업(구글 포토 등)에 있는 사본은 따로 지워야 해요. 저장에 실패한 파일은 원본을 지우지 않아요.

7사진·동영상 보기

  1. 폴더 위쪽에서 보기 크기를 골라요: 크게 보기 · 작게 보기 · 더 작게 보기 · 이름만 보기.
  2. 그 아래 🙈 미리보지 않기 버튼을 누르면 사진·영상 칸이 검게 가려지고, 한 번 더 누르면 다시 보여요.
  3. 파일을 누르면 크게 열리고, 좌우로 밀면 사진과 동영상이 차례로 넘어가요.
  4. 동영상: 가운데 큰 ▶로 재생, 화면 왼쪽·오른쪽을 누르면 10초 이동, 아래 버튼으로 전체화면 · 가로로 · 배속(0.5~2배) · 소리/무음.
  5. 화면을 한 번 톡 치면 버튼이 숨고, 다시 치면 나타나요.

8파일 옮기기 (다른 폴더·다른 방)

  1. 폴더 안에서 선택을 누르고 옮길 파일을 탭해요. 전체 선택 / 해제도 있어요.
  2. 아래 이동을 누르고 옮길 곳을 골라요.
  3. 같은 비밀방의 다른 폴더: 도착 폴더를 고르거나 새 폴더를 만들면 끝이에요.
  4. 다른 비밀방 (이용권): 작업 비밀번호 → 도착할 방의 그림 위치 + 패턴 → 도착 폴더 순서로 진행해요. 도착 방에 안전하게 저장된 것을 확인한 뒤에 원래 방에서 지워요.

9폰으로 복원·삭제

  1. 폰으로 복원: 파일을 열고 위쪽 복원을 누르거나, 선택 모드에서 폰으로 복원을 눌러요. 작업 비밀번호를 확인한 뒤 저장 위치를 고르면 암호화가 풀린 일반 파일로 저장돼요. 비밀방 보관본은 그대로 남아요.
  2. 삭제: 선택 모드에서 빨간 삭제 → 경고 확인 → 작업 비밀번호. 휴지통 없이 지워지고 되돌릴 수 없어요.

💡 앱을 지우거나 폰을 바꾸기 전에는 꼭 필요한 파일을 폰으로 복원해 두세요. 별담은 서버에 백업하지 않아요.

10비밀방 추가하기 (이용권)

  1. 비밀방 → 설정 → 새 비밀방 만들기를 눌러요.
  2. 방 이름을 정하고, 그림에서 다른 위치를 골라 패턴을 두 번 그려요. 이미 쓰는 위치는 회색 ×로 보여서 고를 수 없어요.

💡 무료는 비밀방 1개예요. 두 번째 방부터는 이용권이 필요하고, 무료 상태에서 누르면 안내 창이 떠요. 이용권이 끝나도 이미 만든 방은 그대로 쓸 수 있어요.

11패턴·작업 비밀번호 바꾸기

  1. 입장 패턴: 설정 → 이 방 입장 패턴 변경 → 새 패턴을 두 번 그려요. 그림 위치와 파일은 그대로예요.
  2. 작업 비밀번호: 설정 → 공통 작업 비밀번호 변경 → 지금 비밀번호 확인 → 새 비밀번호 두 번. 모든 비밀방에 함께 적용돼요.

12자동 잠금

아래 상황에서는 바로 잠기고, 다시 들어오려면 그림 위치와 패턴이 필요해요.

  • 홈으로 나가거나 다른 앱으로 넘어갈 때
  • 화면을 끌 때
  • 분할 화면·팝업 창에서 옆 앱을 누를 때
  • 광고나 링크를 눌러 브라우저로 넘어갈 때

💡 별담이 직접 연 화면(파일 고르기, 저장 위치 고르기, 삭제 승인)에 있는 동안은 최대 5분까지 잠기지 않아요. 최근 앱 화면과 스크린샷에도 내용이 보이지 않아요.

13일상방 채워 두기

그림 위치를 누른 뒤 등록하지 않은 패턴을 그리면 일상방이 열려요. 일상방도 비밀방처럼 사진·동영상·파일을 넣고 볼 수 있어요.

  1. 그림 위치를 누르고, 비밀방 패턴이 아닌 아무 패턴이나 그려 일상방에 들어가요.
  2. 기본 사진 폴더나 새 폴더에서 파일 추가를 눌러 풍경·음식·여행 사진 같은 평범한 사진을 넣어 두세요.
  3. 이렇게 채워 두면 누가 별담을 열어 봐도 평범한 사진 앨범처럼 보여요.

💡 일상방은 등록하지 않은 패턴이면 누구나 열 수 있는 방이에요. 지켜야 할 사진은 꼭 비밀방에 넣으세요. 일상방 파일도 저장 공간(무료 1GB)에 함께 계산되고, 비밀방 개수에는 들어가지 않아요. 입구·패턴 설정과 방 추가 메뉴는 비밀방 설정에만 있어요.

화면 그림은 실제 앱 화면을 바탕으로 다시 그린 예시로, 기기에 따라 조금 다를 수 있어요. 궁금한 점은 moruappstudio@gmail.com 으로 보내 주세요.
